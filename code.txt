4. Report a conflict when overlapping classes use the same room; also report student timetable overlaps.

Flowchart
START -> Prepare input data -> Process using loops/conditions -> Check rules and calculate -> Display results -> END

Pseudocode

Question 35: Text Compression Using Character Runs


Problem Statement
Encode a string by grouping consecutive repeated characters and compare original and encoded lengths, including cases where encoding is not beneficial.

Objectives
- Count consecutive repeated characters.
- Create a run-length encoded string.
- Use the encoded form only when it is shorter.

Assumptions
- Input contains ordinary characters without spaces for this demonstration.
- Each group is represented by the character followed by its count.
- If the encoded string is not shorter, the original string is retained.

Algorithm
1. Read a string.
2. Track the current character and its run count.
3. When the character changes, append the previous character and count.
4. Append the final run.
5. Compare encoded and original lengths and print the shorter representation.

Flowchart
START -> Prepare input data -> Process using loops/conditions -> Check rules and calculate -> Display results -> END

Pseudocode
INPUT text
encoded = empty string
count = 1
FOR i from 1 to length(text)-1
    IF text[i] == text[i-1]: count = count + 1
    ELSE append text[i-1] and count; count = 1
IF text is not empty: append last character and count
IF length(encoded) < length(text): PRINT encoded
ELSE PRINT original text

Python Source Code
# Question 35: Text Compression Using Character Runs
text = "aaabbccccd"
encoded = ""
if text != "":
    count = 1
    for i in range(1, len(text)):
        if text[i] == text[i - 1]:
            count += 1
        else:
            encoded += text[i - 1] + str(count)
            count = 1
    encoded += text[-1] + str(count)
print("Original:", text)
print("Encoded:", encoded)
print("Original length:", len(text))
print("Encoded length:", len(encoded))
if len(encoded) < len(text):
    print("Use encoded text:", encoded)
else:
    print("Compression is not beneficial; keep original.")

- A question with fewer than 50% correct responses is classified as Difficult.

Algorithm
1. Store the answer key and student answer strings.
2. For each question position, count correct answers across students.
3. Calculate success percentage for each question.
4. Identify the question with the lowest success rate and classify questions.

Flowchart
START -> Prepare input data -> Process using loops/conditions -> Check rules and calculate -> Display results -> END

Pseudocode
INPUT answer key and student answer strings
FOR each question position
    correct = 0
    FOR each student answer
        IF answer matches key: correct += 1
    percentage = correct / number of students * 100
    IF percentage < 50: classify Difficult
    PRINT question and percentage
Find question with minimum correct count

Python Source Code
# Question 87: Examination Question Difficulty and Performance Analysis
answer_key = "ABCA"
answers = ["ABCA", "ABBA", "CBCA", "A-CA"]
student_count = len(answers)
correct_counts = []
for q in range(len(answer_key)):
    correct = 0
    for answer in answers:
        if q < len(answer) and answer[q].upper() == answer_key[q]:
            correct += 1
    correct_counts.append(correct)
    percentage = correct / student_count * 100
    difficulty = "Difficult" if percentage < 50 else "Acceptable"
    print("Question", q + 1, "- correct:", correct,
          "success:", round(percentage, 1), "% -", difficulty)
hardest_index = correct_counts.index(min(correct_counts))
print("Most frequently missed question:", hardest_index + 1)
