# Python-Activity-Based-Learning

This repository contains 10 Python Activity-Based Learning case studies selected from the supplied list of 100.

## Selected case studies
- Question 23: Student Timetable Conflict Detection
- Question 28: Repeated Transaction Detection
- Question 35: Text Compression Using Character Runs
- Question 42: Student Marks Matrix Analysis
- Question 48: Tuple-Based Employee Shift Conflict Detection
- Question 55: Tuple-Based Transaction Audit
- Question 61: Nested List Examination Seating Validation
- Question 66: Student Academic Risk Classification
- Question 75: Integrated Student Record Consistency Checker
- Question 87: Examination Question Difficulty and Performance Analysis

## Folder structure
- `programs/`: 10 Python source files.
- `flowcharts/`: text flowchart outlines for each program.
- `output_screenshots/`: PNG captures of sample program outputs.
- `Python_ABL_Consolidated_Report.pdf`: consolidated report containing problem statements, objectives, assumptions, algorithms, flowchart outlines, pseudocode, code, test cases, sample output, and conclusions.

## How to run
Use Python 3. Run any program, for example:
`python programs/Q35_text_compression_using_character_runs.py`

The programs use only core Python features such as variables, data types, operators, conditional statements, loops, strings, lists, nested lists, tuples, and tuple unpacking. No external Python packages are required to run the student programs.
